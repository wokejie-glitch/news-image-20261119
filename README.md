A program that draws a newspaper front page summing up 19 November 2026's world news in one image: the Shenzhen trilateral summit, the Gaza ground operation, the Ethiopia-Eritrea clashes, the Kumamoto earthquake and Cyclone Xavier. It uses pure Python stdlib only — no network, no third-party packages.

## Run it

mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
